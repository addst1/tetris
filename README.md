# ARCADE BLOCKS — Neon Edition

네온 아케이드 감성의 블록 퍼즐 **PWA**. 외부 라이브러리·음원·이미지 파일 없이 순수 HTML/CSS/JS(WebAudio)로 만들었고, 갤럭시 같은 스마트폰 터치 조작과 화면 비율에 맞춰져 있습니다.

## 조작

| 터치 | 동작 |
|---|---|
| 좌우 드래그 | 블록 이동 (손가락을 1:1로 따라감) |
| 화면 오른쪽 탭 | 시계 방향 회전 |
| 화면 왼쪽 탭 | 반시계 방향 회전 |
| 드래그 중 다른 손가락 탭 | 이동을 멈추지 않고 회전 (두 엄지 조작) |
| 아래로 드래그 | 소프트 드롭 (1칸당 +1점) |
| 아래로 빠르게 플릭 | 하드 드롭 (1칸당 +2점) |

PC: `←` `→` 이동 / `↑` `X` 시계 회전 / `Z` 반시계 회전 / `↓` 내리기 / `Space` 하드 드롭 / `P` 일시정지

## 화면 구성과 동적 레이아웃

- 네온 UI: 무지개 네온 로고, 노란 SCORE / ROUND, 보라 구분선, 시안 네온 테두리의 격자 플레이필드, 속이 빈 네온 블록
- **세로(폰)**: 헤더(로고 · 점수/레벨/LEFT · 큰 NEXT) / 화면 폭을 꽉 채우는 플레이필드 / 하단 일시정지·소리 아이콘 버튼
- **가로(폴드 펼침, 태블릿, PC)**: 왼쪽 로고 + 점수 박스 + 버튼 / 가운데 플레이필드 / 오른쪽 NEXT + LEFT
- 블록 크기는 화면 크기와 기기 픽셀 비율에 맞춰 정수 픽셀로 계산됩니다. 노치 영역은 `safe-area` 로 회피합니다.

## 아케이드 요소

- 피스마다 다른 색의 네온 유리 블록, 얇은 CRT 스캔라인과 비네팅
- NES식 규칙: 레벨별 프레임 중력, 한 줄 40 / 두 줄 100 / 세 줄 300 / 네 줄 1200 × 라운드, **LINES LEFT** 가 0이 되면 ROUND CLEAR
- **ROUND CLEAR 이벤트**: 배경음이 멈추고 전용 8비트 춤곡에 맞춰 무용수들이 춤추는 장면(점프, 쪼그려 앉기, 발차기)이 나오고 색종이와 불꽃이 터집니다. 라운드가 오르면 무용수가 늘어납니다(최대 3명). 5라운드마다 이어서 로켓 발사 카운트다운 연출이 나옵니다. 화면을 탭하면 건너뜁니다. 4줄 동시 제거 시에는 플래시 + 팡파르.
- 무용수, 배경 실루엣, 로켓은 모두 직접 그린 일반적인 도형이며 기존 게임의 캐릭터나 그림을 쓰지 않았습니다.
- **ROUND CLEAR 후 판 초기화**: 보드를 비우고 새 라운드를 시작하며, 남은 빈 높이 × 100점 보너스를 줍니다. 높은 라운드는 시작할 때 바닥에 잔해(구멍 뚫린 줄)가 깔립니다. (`rubbleRows()`)
- **폭탄 칸**(검은 공): 일반 블록처럼 쌓이다가, 폭탄 칸이 든 줄이 지워지는 순간 주변 5×5 블록이 폭발해 사라집니다. (지워지는 줄 밖의 블록만 해당)
- **별 블록**(노란 별): 별이 든 줄을 지우면 `500 × 라운드` 보너스가 붙습니다.
- **콤보**: 연속으로 줄을 지우면 보너스와 효과음 음정 상승
- **퍼펙트 클리어**: 줄을 지워 판이 완전히 비면 `3000 × 라운드`
- **위험 경고**: 쌓인 높이가 16줄 이상이면 필드 테두리가 붉게 깜빡임
- **이어하기**: 앱을 최소화하면 자동 일시정지되고, 블록이 나올 때마다 진행 상황이 저장됩니다. 브라우저가 앱을 종료했더라도 타이틀의 CONTINUE로 이어서 할 수 있습니다.
- **하드드롭 궤적**: 빠르게 휙 내릴 때만 떨어진 경로에 잠깐 빛 자국이 남습니다.
- **고스트 블록**: 착지 위치 미리보기 (타이틀에서 ON/OFF)
- **고정 지연(lock delay)**: 바닥에 닿은 뒤 최소 0.5초 동안 이동/회전할 수 있고, 바닥에서 이동·회전에 성공하면 타이머가 되돌아갑니다(최대 15회). 고정이 가까워지면 블록이 흐려집니다. 바닥에서 아래로 드래그해도 즉시 고정되지 않습니다. (`lockDelay()`, `MAX_RESETS`)
- **TAP 설정**: `SPLIT`(왼쪽 탭 = 반시계, 오른쪽 탭 = 시계) / `CW`(어디를 탭해도 시계). 타이틀에서 바꿉니다.
- 8비트 사운드: 펄스파 + 삼각파 + 노이즈 드럼. 배경음 5곡(코로베이니키 + 오리지널 4곡)이 라운드마다 자동으로 바뀌고 라운드가 오를수록 템포 상승. 소리 아이콘으로 전체 ON/OFF
- **기록**: TOP 10 + 3글자 이니셜, 통계(게임 수, 누적 줄, 4줄 제거 횟수), 기록 초기화(2번 탭 확인)

## 로컬 실행

서비스워커는 `file://`에서는 동작하지 않으므로 간단한 서버로 열어 주세요.

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## GitHub Pages 배포

1. 이 폴더 전체를 저장소에 push
2. 저장소 **Settings → Pages → Branch: `main` / `(root)`** 선택 후 저장
3. `https://<계정>.github.io/<저장소>/` 에 접속
4. 갤럭시(Chrome/삼성 인터넷): 메뉴 → **홈 화면에 추가 / 앱 설치**. 설치한 앱은 상태바 없이 전체화면으로 실행됩니다. 설치하지 않고 브라우저에서 할 때는 타이틀의 **FULLSCREEN** 버튼을 사용하세요.

경로는 모두 상대경로라서 하위 경로(`/<저장소>/`)에서도 그대로 동작합니다.

## 파일 구성

```
index.html            화면 구조 (HUD, 돌기둥, 플레이필드, 오버레이 화면)
style.css             아케이드 스타일 (--cell / --f 변수로 크기 조절, 세로/가로 레이아웃)
game.js               게임 로직 / 터치 입력 / 동적 크기 계산 / 사운드 / 기록 / 이벤트
sw.js                 서비스워커 (오프라인 캐시)
manifest.webmanifest  PWA 설정 (fullscreen, 회전 허용)
icons/                생성된 아이콘
```

## 커스터마이징 포인트 (`game.js`)

- 블록 색: `PIECE_COLORS` (I, O, T, S, Z, J, L 순서)
- 곡/템포: `TRACKS` 의 음표 문자열(`E5:1` = 미 5옥타브, 1박)과 `bpm`
- 속도 곡선: `GRAVITY` 배열, 점수표: `LINE_SCORE`
- 로켓 이벤트 주기: `startEvent()` 의 `G.level % 5`
- 레이아웃 비율: `fit()` 의 `hdrH`, `ftrH`, 글자 크기 `f` 계산식

## 참고

- **삼성 갤럭시 제스처 내비게이션**: 화면 맨 왼쪽/오른쪽 가장자리에서 시작하는 스와이프는 시스템 '뒤로 가기'로 처리될 수 있습니다. 블록 이동 스와이프는 화면 가운데에서 시작하세요.
- **iPhone**: 무음 스위치가 켜져 있으면 웹 오디오가 나오지 않습니다. 소리는 첫 터치 이후부터 재생됩니다.
- **배포 후 수정할 때**: `sw.js` 의 `CACHE` 버전(`retro-blocks-v7`)을 올려야 설치된 앱에 변경이 반영됩니다. 타이틀 하단에 표시되는 버전은 `game.js` 맨 위의 `VERSION` / `BUILD` 상수입니다. 둘을 같이 올리세요.
- **이름/상표**: "Tetris"는 The Tetris Company의 상표입니다. 공개 저장소에는 `ARCADE BLOCKS` 같은 다른 이름을 쓰는 것이 안전합니다. 이 프로젝트의 그래픽(로고, 아이콘, 로켓 등)은 직접 그린 것이며 아타리 등 기존 게임의 그림·음원은 사용하지 않았습니다. 배경음 A는 러시아 민요 *코로베이니키*(퍼블릭 도메인)를 직접 편곡한 것입니다.
