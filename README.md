# RETRO BLOCKS — Arcade Edition

아케이드 오락실 감성의 블록 퍼즐 **PWA**. 외부 라이브러리·음원·이미지 파일 없이 순수 HTML/CSS/JS(WebAudio)로 만들었고, 갤럭시 같은 스마트폰 터치 조작과 화면 비율에 맞춰져 있습니다.

## 조작

| 터치 | 동작 |
|---|---|
| 탭 | 블록 회전 |
| 좌우 스와이프 | 블록 이동 (손가락을 1:1로 따라감) |
| 아래로 드래그 | 소프트 드롭 (1칸당 +1점) |
| 아래로 빠르게 플릭 | 하드 드롭 (1칸당 +2점) |

PC: `←` `→` 이동 / `↑` `Z` `X` 회전 / `↓` 내리기 / `Space` 하드 드롭 / `P` 일시정지

## 화면 구성과 동적 레이아웃

- 프레임 없이 전체 화면을 사용합니다. 노치/펀치홀/제스처 바 영역은 `safe-area` 로 자동 회피합니다.
- **세로(폰)**: 위쪽 NEXT · 아치 로고 + LINES LEFT · ROUND / 가운데 돌기둥 + 플레이필드 / 아래쪽 SCORE · HIGH · LINES, STATS 막대, 버튼
- **가로(폴드 펼침, 태블릿, PC)**: 플레이필드가 가운데, 좌우에 정보 패널과 돌기둥
- 블록 크기는 화면 크기와 기기 픽셀 비율에 맞춰 정수 픽셀로 계산되므로 어떤 갤럭시(S/A/Z 시리즈)에서도 선명하게 맞습니다. 회전, 폴드 전개, 창 크기 변경도 즉시 반영됩니다.

## 아케이드 요소

- 피스마다 다른 색의 입체 블록, 얇은 CRT 스캔라인과 비네팅
- NES식 규칙: 레벨별 프레임 중력, 한 줄 40 / 두 줄 100 / 세 줄 300 / 네 줄 1200 × 라운드, **LINES LEFT** 가 0이 되면 ROUND CLEAR
- **ROUND CLEAR 이벤트**: 컬러 불꽃놀이 + 보너스, 5라운드마다 로켓 발사 카운트다운 연출, 4줄 동시 제거 시 플래시 + 팡파르
- **STATS**: 나온 블록 종류별 막대 그래프
- 8비트 사운드: 펄스파 + 삼각파 + 노이즈 드럼. 음악 A(코로베이니키) / B(오리지널) / OFF, 라운드가 오를수록 템포 상승
- **기록**: TOP 10 + 3글자 이니셜, 통계(게임 수, 누적 줄, 4줄 제거 횟수), 기록 초기화(2번 탭 확인)

## 로컬 실행

서비스워커는 `file://`에서는 동작하지 않으므로 간단한 서버로 열어 주세요.

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## GitHub Pages 배포

1. 이 폴더 전체를 저장소에 push
2. 저장소 **Settings → Pages → Branch: `main` / `(root)`** 선택 후 저장
3. `https://<계정>.github.io/<저장소>/` 에 접속
4. 갤럭시(Chrome/삼성 인터넷): 메뉴 → **홈 화면에 추가 / 앱 설치**. 설치한 앱은 상태바 없이 전체화면으로 실행됩니다. 설치하지 않고 브라우저에서 할 때는 타이틀의 **FULLSCREEN** 버튼을 사용하세요.

경로는 모두 상대경로라서 하위 경로(`/<저장소>/`)에서도 그대로 동작합니다.

## 파일 구성

```
index.html            화면 구조 (HUD, 돌기둥, 플레이필드, 오버레이 화면)
style.css             아케이드 스타일 (--cell / --f 변수로 크기 조절, 세로/가로 레이아웃)
game.js               게임 로직 / 터치 입력 / 동적 크기 계산 / 사운드 / 기록 / 이벤트
sw.js                 서비스워커 (오프라인 캐시)
manifest.webmanifest  PWA 설정 (fullscreen, 회전 허용)
make_icons.py         아이콘 PNG 생성 스크립트 (python3 make_icons.py)
icons/                생성된 아이콘
```

## 커스터마이징 포인트 (`game.js`)

- 블록 색: `PIECE_COLORS` (I, O, T, S, Z, J, L 순서)
- 곡/템포: `TRACKS` 의 음표 문자열(`E5:1` = 미 5옥타브, 1박)과 `bpm`
- 속도 곡선: `GRAVITY` 배열, 점수표: `LINE_SCORE`
- 로켓 이벤트 주기: `startEvent()` 의 `G.level % 5`
- 레이아웃 비율: `fit()` 의 `hdrH`, `ftrH`, 글자 크기 `f` 계산식

## 참고

- **삼성 갤럭시 제스처 내비게이션**: 화면 맨 왼쪽/오른쪽 가장자리에서 시작하는 스와이프는 시스템 '뒤로 가기'로 처리될 수 있습니다. 블록 이동 스와이프는 화면 가운데에서 시작하세요.
- **iPhone**: 무음 스위치가 켜져 있으면 웹 오디오가 나오지 않습니다. 소리는 첫 터치 이후부터 재생됩니다.
- **배포 후 수정할 때**: `sw.js` 의 `CACHE` 버전(`retro-blocks-v2`)을 올려야 설치된 앱에 변경이 반영됩니다.
- **이름/상표**: "Tetris"는 The Tetris Company의 상표입니다. 공개 저장소에는 `RETRO BLOCKS` 같은 다른 이름을 쓰는 것이 안전합니다. 이 프로젝트의 그래픽(아치, 돌기둥, 로켓 등)은 직접 그린 것이며 아타리 등 기존 게임의 그림·음원은 사용하지 않았습니다. 배경음 A는 러시아 민요 *코로베이니키*(퍼블릭 도메인)를 직접 편곡한 것입니다.
